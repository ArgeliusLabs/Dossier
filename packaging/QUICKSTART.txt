DOSSIER - QUICK START
=====================

1. (Optional) Turn on the AI analyst
   Open config.json (in this folder) with any text editor and paste your OpenAI key
   between the quotes on the "openai_api_key" line. Save it.
   No key? Dossier still works; you just don't get the AI write-up.
   Prefer a local model (Ollama / LM Studio)? Instructions are inside config.json.

2. Open a terminal in this folder
   Windows: right-click the folder background > "Open in Terminal"
   macOS/Linux: open Terminal and cd into this folder

3. Analyse an extension (paste a store link, an ID, or a .crx/.xpi file)
   Windows:      .\dossier.exe "https://chromewebstore.google.com/detail/<name>/<id>" --open
   macOS/Linux:  ./dossier "https://addons.mozilla.org/firefox/addon/<name>/" --open

   IMPORTANT: put the link in "double quotes". Store links often contain "&" (like ?hl=en&pli=1),
   and without quotes Windows cuts the link there and shows an error such as
   'pli' is not recognized as an internal or external command. Or skip the link and use the ID,
   the 32 letters at the end of a Chrome Web Store link:
   Windows:      .\dossier.exe "https://chromewebstore.google.com/detail/name/abcdefghijklmnopabcdefghijklmnop?hl=en&pli=1"
                 .\dossier.exe abcdefghijklmnopabcdefghijklmnop

   Audit everything installed in your own browsers:
   Windows:      .\dossier.exe --installed --open
   macOS/Linux:  ./dossier --installed --open

Reports are saved in a "reports" folder and open in your browser with --open.
Run with --help for every option.

macOS: if it says the app can't be opened, run once:  xattr -d com.apple.quarantine ./dossier
Windows: if SmartScreen warns, click "More info" > "Run anyway" (the binary is not code-signed).

Keep config.json private: it contains your API key.
Docs: https://github.com/ArgeliusLabs/Dossier
